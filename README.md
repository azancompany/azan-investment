# Azan Investment Website (Bilingual)

Static bilingual website (Arabic/English) for GitHub Pages.

## Publish
Settings → Pages → Source: Deploy from a branch
Branch: main | Folder: /root

## Structure
- Arabic at root: index.html, about.html, services.html, contact.html
- English under /en: en/index.html, en/about.html, en/services.html, en/contact.html

## Notes
- Update Formspree action to your form ID.
- Place your logo in assets/img/logo.png
